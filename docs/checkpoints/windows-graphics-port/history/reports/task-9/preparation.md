## Minimal implementation after GO

1. **Reuse the shared/default atlas.** Extend the Task 8 native `t14` upload path to accept the existing packed CPU texture and its exact mapping/channel/time constants. Keep the two logical tiles in one one-mip resource. A failed create/mirror/upload marks shore history unavailable for that draw, publishes no `OwnShore`, and leaves authored tracks intact. Camera remapping changes only the sampled window; fixed-world CPU history remains unchanged.
2. **Retain a truthful shore record per accepted patch/view.** On complete native submission, retain the exact receipt stamp, original polygon/level, and AddRef'd height/optical SRVs needed later by authored tracks. Publish it only when `ReplacementOwnership(prepared)` contains `OwnShore`; degraded/local fallback draws never enter this ledger. Clear frame records at `End`, revoke them on device loss, and invalidate matching resources on target/resize/device/map changes. Do not let a native owner synthesize replacement ownership from resource presence alone.
3. **Admit the complete animated authored track.** Remove only the track metadata `_WIN32` exclusion. Before substituting the pixel program, require authored source, real water handle, non-editor/non-WorldBuilder, the existing eligible draw state, valid convex four-corner footprint, exact level, a live `QueryCurrentView`, and `CoveredByUnion(track, currentStamp, acceptedRegions, OwnShore)`. Adjacent accepted patches may prove the whole track; partial, disjoint, wrong-winding, wrong-level, stale-view, stale-capture, or failed-water coverage retains the original draw.
4. **Wrap rather than replace geometry.** Compile the canonical original fixed-function combiner and `GenerateShorePixel` as `ps_5_0` through `DX11BackendClass::Compile_Program`. Bind its dedicated 176-byte PS `b0`; preserve authored material stages and vertex/index buffers; bind retained height `t2`, optical `t4`, and the exact once-before-first-water original depth `t6` with point/no-mip sampling. Draw the original full quad through the wrapper. The wrapper preserves the original fog, shroud, alpha test, texture animation, and source-over blend, and depth-occludes moving scene objects. On any pre-draw validation/compile/resource failure, issue the untouched legacy draw.
5. **Never capture late.** The shore lookup may only reuse the scene pair captured before the first modern surface for that view/frame. Missing original depth, a changed target/view/viewport, or Classic-before-valid-pair refuses the wrapper. A track draw cannot call `Capture_Scene`, cannot substitute current mutable depth, and cannot use equal dimensions as identity.
6. **Install optional coastal state transactionally.** Under the launch-time `SURF_GPU` snapshot only, serialize the immutable CPU domain into five one-mip 256x256 RGBA32F textures, allocate three state pings plus one incident input, and retain exact revision/count/spacing/payload identity. Allocation, format, compilation, upload, or revision mismatch leaves the prior valid revision intact or disables only coastal composition; it never affects default shore history.
7. **Run the exact coastal sequence.** Inspect the shared clock without mutation. For `Sample`: validate exact Task 7 FFT phase/revision, run incident, reaction, diffusion. For `GapDecay`: run incident and reaction, with source disabled by the plan flag. For `Reset`: reaction clears/restarts without diffusion. For `None`: validate/commit no GPU work. Submit all required passes before committing clock/active ping/update count. Any failure retains the previous addressable state and does not advance sampled/observed time.
8. **Resolve the camera view separately.** Validate revision, exact level, mapping, lookup count and every node/weight against the immutable domain. Keep ID, weight, and output textures one-mip RGBA32F; point-sample IDs/weights/state/world and expose the output with clamp-linear at `t15`. Mark it ready only for the exact history update and sampled time used to produce it. Resize/camera motion rebuilds only view resources; fixed-world coastal history survives.
9. **Select opt-in shader variants without changing defaults.** Snapshot `ZH_WATER_SURF_GPU` and `ZH_WATER_COAST_CREST` once at launch with the existing `WaterGpuShaders::SnapshotEnvironment(Target, materialFvf)`; never reread them per draw. Default production variants retain shore foam/history but have coastal surf and crest false. SURF-only, SURF+CREST, and debug variants use distinct existing `WaterGpuShaders::Key` values. Crest is invalid without SURF and remains off for rivers.
10. **Restore native state.** Every shore/coastal path must detach conflicting OM outputs and overlapping SRVs, then restore actual targets, viewport/scissor, pipeline and backend bookkeeping. Explicitly clear PS `t14-t15`, utility inputs, samplers, cbuffers, and internal VB/IB before the next ordinary draw. No submit-time allocation/compilation is allowed in the authored-track draw.

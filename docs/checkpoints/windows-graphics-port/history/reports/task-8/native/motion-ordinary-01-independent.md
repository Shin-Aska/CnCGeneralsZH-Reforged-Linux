# Independent manual QA: ordinary native motion capture

Scope is limited to `boundedcapture` and `observedmotion` for the sealed single ordinary Windows native D3D11 run. This review did not launch a game, CPU scenario, build, or GPU test. It independently checked the full 776-entry seal (all sizes and SHA-256 values), parsed all 721 BMP headers and captured-clock rows, compared the 17 runtime pins, checked the stage/build hashes, read the run’s command and process receipts, and personally viewed the 12 preregistered original BMPs. The sealed bundle is `motion-ordinary-01-execution`; the original run outputs are its sibling `motion-ordinary-01/20261018-022214`.

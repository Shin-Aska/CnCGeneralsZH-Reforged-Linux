### Lower RAM use on Vulkan

Scrolling around a map could keep several extra gigabytes of system RAM in use, especially with
HD assets. The renderer now lets SDL reclaim the temporary memory once the GPU finishes an upload.

On the USA 2 save, we panned the same route twice at normal zoom, returned to the starting view
and waited three minutes. The game's share of resident RAM (PSS) grew by **80 MiB** with the fix,
compared with **2.93 GiB** on the 4.2.1 AppImage. Both runs used an RTX 4060 at 1920 × 1080
with all 14 HD archives. The AppImage used synchronized GPU submission during loading. Both
runs used normal asynchronous submission throughout the measured interval.

Multiplayer requires matching game versions and bundled data.

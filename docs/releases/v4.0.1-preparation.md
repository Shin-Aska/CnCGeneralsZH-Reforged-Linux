## Validation scope

The hosted release pipeline uses the Sniper SDK, asset-independent tests with
Mesa Lavapipe/Xvfb, and distribution package checks. It does not establish full
hardware gameplay, every campaign/save/replay path, cross-version multiplayer,
Flatpak portals or Steam Deck gameplay. Feature-specific local checks retain the
binaries and dates recorded in the [Linux guide](../linux.md),
[campaign audit](../campaign-opening-audit.md), [cinematic report](../campaign-cinematic-smoothing.md)
and [upstream tracker](../upstream-status.md); they are not relabelled as a new
hardware qualification of the 4.0.1 package.

The release headline is **reworked FFT water, expanded native Linux effects and
campaign fixes**. Underwater clarity, Path traced reflections, extended volumetric
toxin effects and Asset Preloading are retained features from earlier fork releases.
This release does not claim a new upstream version synchronization or a merge of
fork-only work upstream.

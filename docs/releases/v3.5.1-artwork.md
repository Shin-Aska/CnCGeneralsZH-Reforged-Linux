# 3.5.1 launch artwork

The release card follows the user's annotated original layout: the same title,
version, bullets, dark fade and angled insets. The left inset is split horizontally
with Low wave detail (128×128 FFT) above High wave detail (256×256 FFT). The right
inset shows sharper path tracing reflections. The main caption reads “Waves now
follow the shore”.

Gameplay comes only from the user's actual screenshot files. They are resized
proportionally and clipped into the original panel shapes. No gameplay content is
generated, reconstructed or retouched. The approved typography and gold rules are
retained as a separate transparent graphic from the initial design.

- `v3.5.1-shore-waves-refraction.png`: the supplied hero screenshot with
  refractions enabled, `codex-clipboard-ec0932e0-0cc4-42aa-96dd-bb310895f8d4.png`.
- `v3.5.1-low-wave-detail.png`: original screenshot 5,
  `codex-clipboard-beb4c961-88a0-4ed5-a85a-9a94c12ec06c.png`, 128×128 FFT.
- `v3.5.1-sunlit-water.png`: original screenshot 4,
  `codex-clipboard-c29435a4-2fbb-4b5e-9687-8193f4c94822.png`, 256×256 FFT.
- `v3.5.1-reflections.png`: original screenshot 6,
  `codex-clipboard-ea5a98a9-4edb-41ce-97bc-91250ee0a2ff.png`.
- `v3.5.1-title-treatment.png`: approved typography and gold rules, transparent
  elsewhere; contains no gameplay scene.
- `v3.5.1-launch-annotated-layout-v2.png`: final 1672×941 card with the
  refraction-enabled hero. This fresh filename avoids cached previews.

All images live in `.github/media/releases/`. The supplied source PNGs are retained
unchanged. Rebuild using the existing Pillow library and system DejaVu Sans fonts:

```sh
python3 .github/scripts/create-v3.5.1-launch.py
```

Release media is updated separately from the engine tag. The release page embeds
the final media asset directly, while `main` retains its sources and composition
script.

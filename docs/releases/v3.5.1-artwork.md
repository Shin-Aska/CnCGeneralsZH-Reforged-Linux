# 3.5.1 launch artwork

The published launch card uses the user's original screenshots as supplied.
They are pasted at native resolution with no cropping, scaling, retouching,
colour changes, HUD removal, overlays over the screenshots, or AI reconstruction.
The title, version and feature descriptions occupy separate areas of the canvas.

- `.github/media/releases/v3.5.1-water.png`: supplied screenshot 3,
  `codex-clipboard-f4b4c9a7-8b33-4112-851e-2fc3124a3d0c.png`.
- `.github/media/releases/v3.5.1-reflections.png`: supplied screenshot 6,
  `codex-clipboard-ea5a98a9-4edb-41ce-97bc-91250ee0a2ff.png`.
- `.github/media/releases/v3.5.1-launch.png`: final 2720×1530 release card.

Rebuild using the existing Pillow library and system DejaVu Sans fonts:

```sh
python3 .github/scripts/create-v3.5.1-launch.py
```

The script checks that each screenshot region in the saved PNG is pixel-identical
to the source. No generated image is included in this release.

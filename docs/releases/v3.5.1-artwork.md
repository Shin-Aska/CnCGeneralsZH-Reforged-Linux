# 3.5.1 launch artwork

The published launch card uses the user's original screenshots, proportionally
resized to fit the layout. There is no cropping, retouching, colour adjustment,
HUD removal, text over the screenshots, or AI reconstruction. The title, version
and feature descriptions occupy a separate sidebar, with a main gameplay panel,
paired Low/High wave-detail screenshots and a path-traced reflection close-up.

- `.github/media/releases/v3.5.1-water.png`: supplied screenshot 1,
  `codex-clipboard-4b8021aa-f263-482b-9a37-1dcb40430090.png`.
- `.github/media/releases/v3.5.1-sunlit-water.png`: supplied screenshot 4,
  `codex-clipboard-c29435a4-2fbb-4b5e-9687-8193f4c94822.png`, High wave detail,
  256×256 FFT.
- `.github/media/releases/v3.5.1-low-wave-detail.png`: supplied screenshot 5,
  `codex-clipboard-beb4c961-88a0-4ed5-a85a-9a94c12ec06c.png`, Low wave detail,
  128×128 FFT.
- `.github/media/releases/v3.5.1-reflections.png`: supplied screenshot 6,
  `codex-clipboard-ea5a98a9-4edb-41ce-97bc-91250ee0a2ff.png`.
- `.github/media/releases/v3.5.1-launch.png`: final 2880×1620 release card.

Rebuild using the existing Pillow library and system DejaVu Sans fonts:

```sh
python3 .github/scripts/create-v3.5.1-launch.py
```

The script checks that each screenshot region in the saved PNG matches the
proportionally resized original exactly. No generated image is included in this
release. The unmodified source PNGs are retained alongside the launch card.

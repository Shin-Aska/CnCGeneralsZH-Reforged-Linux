### Map edge

The new terrain beyond the map edge still felt awkward during play, so we’ve temporarily restored
the 4.2.3 edge as the Linux default. Launch with `-terrainSkirt` to try the upstream edge.

### Linux fixes and optimizations

- Paradropped infantry now stay with their selection circles when Ragdoll Deaths is enabled,
  including the Rangers and Missile Defenders at the start of USA mission 2.

We’re carrying forward these Linux changes while their upstream pull requests are open.

- Clean FFT water skips repeated work when drawing large stretches of open water.
  [Upstream PR #283](https://github.com/olcayseygan/CnCGeneralsZH-Reforged/pull/283)
- Completed Vulkan uploads free their buffers for reuse, reducing memory buildup during play.
  [Upstream PR #280](https://github.com/olcayseygan/CnCGeneralsZH-Reforged/pull/280)
- Polluted water is murkier, with duller reflections and a weaker response to wind.
  [Upstream PR #282](https://github.com/olcayseygan/CnCGeneralsZH-Reforged/pull/282)
- The Super Weapon General’s Cold Fusion Reactor glows when the upgraded control rods extend.
  [Upstream PR #281](https://github.com/olcayseygan/CnCGeneralsZH-Reforged/pull/281)

### Startup and Water settings

- Fixed a startup crash with mapped sun shadows enabled before a map has loaded.
- On the **Water** tab, **Underwater Clarity** enables **Refraction** for Modern water. Choose
  **Standard** for distortion from the waves or **Undistorted** for a straight view through the
  surface. The dropdown greys out when clarity is off and retains your selection.

### Downloads

Choose the **AppImage**, **portable archive**, **DEB**, **RPM**, **Arch package**, or **Flatpak bundle**.
You'll need your own Generals and Zero Hour files and a working Vulkan driver. Native packages target
x86_64 Linux with glibc 2.31 or newer. Flatpak uses its declared runtime.

Play older replays using the version that recorded them.

Download all six files listed in `SHA256SUMS` and run `sha256sum --check SHA256SUMS` to verify the complete set.

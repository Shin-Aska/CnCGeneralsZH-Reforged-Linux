**Upstream 4.0.0, with a Linux hotkey fix.**

Zero Hour Reforged Linux 4.0.0 brings this fork up to upstream 4.0.0, including
its gameplay, online and interface updates. This fork keeps its map-aware Modern
water, path-traced reflections, underwater clarity, Volumetric clouds including
Contaminate effects, and asset preloading.

### Missing unit-production hotkeys fixed

Some command-bar buttons lost their shortcuts when their letters were reserved
for fixed order keys (**A S G Y V N C H**). This affected the USA War Factory's Crusader, Humvee,
Ambulance, Sentry Drone, Avenger and Sentry Drone Gun upgrade, among others.
Upstream's fixed order scheme relied on the Windows launcher to assign replacement
keys. Linux has no equivalent launcher.

Linux now keeps each button's original label letter by default. Existing explicit
hotkey choices are respected, and changes made in Options remain saved.
To opt back into fixed order keys, add this to your `Hotkeys.ini`:

```ini
FixedOrderKeys
  Enabled = Yes
End
```

### Also included

- Upstream online play, with lobby, ladder and Quick Match updates.
- Momentum-based vehicle and aircraft deaths, new order cursors, heat haze
  and HUD updates.
- Frame Rate Limit, HD Textures, Detailed Models and Heat Haze options.

See upstream's entries in the full changelog below for details. Optional art
downloads remain separate from the Linux engine packages.

**Replays recorded on earlier versions are incompatible with 4.0.0.**

### Downloads

Choose the **AppImage**, **portable `.tar.zst`**, **DEB**, **RPM**, **Arch package**
or **Flatpak bundle** attached to this release. `SHA256SUMS` covers all six packages;
download every listed file for a complete `sha256sum --check SHA256SUMS` check.

These are engine-only Linux x86_64 packages. **Your own legally owned Generals
and Zero Hour installation is required.** Original game data and optional
upscaled Reforged art are not included. Native packages target glibc 2.31 or newer
with a working Vulkan driver; CI's minimum Ubuntu target is 22.04. Flatpak uses
its declared Freedesktop runtime.

CI checks builds, tests and package installation/startup across Debian, Ubuntu,
Fedora, openSUSE and Arch, using Mesa Lavapipe/Xvfb for renderer checks.
Asset-dependent tests may skip; hardware gameplay, full replay CRC parity,
Flatpak portals and Steam Deck gameplay require separate local validation.
